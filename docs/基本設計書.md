## 5. 認証フロー

### 5.1 メール認証ログイン

```
クライアント           API サーバー            DB
    │                      │                   │
    │── POST /auth/login ──▶│                  │
    │                      │── users 検索 ─────▶│
    │                      │◀──────────────────│
    │                      │── bcrypt 検証      │
    │◀── { accessToken } ──│                   │
    │                      │                   │
    │── GET /users/:id/profile ──▶│            │
    │                      │── settings 取得 ──▶│
    │◀── { profile, settings } ──│             │
```

### 5.2 JWT 運用方針

- トークン有効期限: 30日
- 保存場所: localStorage（`kebo-auth-token`）
- リフレッシュ: 現状は再ログインで対応

## 6. 状態管理設計（フロントエンド）

```
App
└── AppDataProvider（全アプリデータ）
    ├── profile         : ユーザー基本情報
    ├── settings        : 表示設定・言語設定
    ├── posts           : コミュニティ投稿
    ├── rewardSummary   : ポイント・出席・ケボモン情報
    └── LangProvider（言語コンテキスト）
        ├── lang : "ko" | "ja"
        └── t()  : 翻訳関数
```

- 設定変更は `updateSettings()` → サーバー PATCH → `refreshData()` の順で反映
- localStorage にも設定をキャッシュし、初回描画時に即時適用

---

## 7. 多言語対応設計

- 翻訳辞書: `apps/user-web/src/app/lib/i18n.ts`（韓国語・日本語）
- 言語切替: ログイン画面・設定画面から変更可能
- 言語設定保存: `app_settings.language`（サーバー）+ localStorage（キャッシュ）
- 通知内容の多言語化: 通知作成時に `app_settings.language` を参照して言語別テキストを保存
