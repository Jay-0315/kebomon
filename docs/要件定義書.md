# 要件定義書

**プロジェクト名**: KEBO（ケボ）  
**バージョン**: 0.7.5  
**作成日**: 2026-06-11  
**対象**: ユーザー向け Web アプリケーション

---

## 1. プロジェクト概要

KEBO は、旅行・ゲームコミュニティを中心としたエンゲージメント型 Web プラットフォームである。ユーザーは日常的な出席チェック・ミッションをこなしながらポイントを獲得し、ケボモン（オリジナルキャラクター）の収集やバトルを楽しむことができる。  
日本語・韓国語の多言語対応を行い、日韓両国のユーザーを対象とする。

---

## 2. 対象ユーザー

| ユーザー種別 | 説明 |
|---|---|
| 一般ユーザー | 会員登録後にすべての機能を利用できる |
| 管理者（GM） | 管理者ダッシュボードからコンテンツ・ユーザーを管理する |

---

## 3. 機能要件

### 3.1 認証・アカウント管理

| ID | 要件 |
|---|---|
| AUTH-01 | メールアドレスとパスワードによる新規会員登録ができること（メール認証コード方式） |
| AUTH-02 | メール・パスワードによるログインができること |
| AUTH-03 | Google / Kakao / LINE / Apple のソーシャルログインをサポートすること |
| AUTH-04 | 既存アカウントにソーシャルログインを連携できること |
| AUTH-05 | パスワードリセット機能（メール認証コード方式）を提供すること |
| AUTH-06 | アカウント削除（全データ消去）ができること |
| AUTH-07 | JWT によるセッション管理を行うこと |

### 3.2 コミュニティ

| ID | 要件 |
|---|---|
| COM-01 | 投稿を作成・編集・削除できること（テキスト＋画像） |
| COM-02 | 投稿をカテゴリ別（자랑/自慢・공략/攻略・잡담/雑談）で閲覧できること |
| COM-03 | 投稿にいいねができること（1ユーザー1回） |
| COM-04 | 投稿にコメント・返信コメントができること |
| COM-05 | コメントを編集・削除できること |
| COM-06 | 自分の投稿一覧を確認できること |
| COM-07 | 新着コメント時に投稿者へ通知が届くこと |

### 3.3 出席チェック

| ID | 要件 |
|---|---|
| ATT-01 | 1日1回の出席チェックが可能で、50 / 100 / 150P をランダム付与すること |
| ATT-02 | 連続出席日数を記録し、ストリーク値として管理すること |
| ATT-03 | 7日出席ごとに卵（普通・大・黄金）を自動付与すること |
| ATT-04 | 月次累計出席を管理すること |
| ATT-05 | 未出席時は通知ベルに出席リマインダーを表示すること |

### 3.4 ケボモン（キャラクター収集）

| ID | 要件 |
|---|---|
| KAB-01 | ガチャ（1回 / 10回）でケボモンを入手できること |
| KAB-02 | 卵（普通・大・黄金）を孵化してケボモンを入手できること |
| KAB-03 | ピティ（レア保証）・天井（レジェンダリー保証）システムがあること |
| KAB-04 | 重複入手時はポイントに変換されること |
| KAB-05 | 図鑑でコレクション一覧を確認できること |
| KAB-06 | 1体のケボモンをメインキャラクターとして装備できること |
| KAB-07 | ケボモンを強化石で強化（最大レベルまで）できること |
| KAB-08 | 強化石をポイントショップで購入できること |

### 3.5 業績・称号システム

| ID | 要件 |
|---|---|
| ACH-01 | 出席・ミッション・コミュニティ・バトルなど複数カテゴリの業績が存在すること |
| ACH-02 | 業績達成時にケボモンを報酬として付与すること |
| ACH-03 | 称号を獲得・装備できること |
| ACH-04 | シーズンランキング上位者に特別称号を付与できること |
| ACH-05 | 隠し業績（条件非公開）が存在すること |

### 3.6 ミッションレイド

| ID | 要件 |
|---|---|
| RAI-01 | 最大5名が参加できるリアルタイムレイドを提供すること |
| RAI-02 | レイド種別：ジャンプ・クイズ・書き取り・弾幕の4種類をサポートすること |
| RAI-03 | レイドクリア時に卵・ポイントを報酬として付与すること |
| RAI-04 | 同一レイドの再挑戦に4時間のクールダウンを設けること |
| RAI-05 | ユーザーがクイズ・書き取りコンテンツを投稿できること |

### 3.7 コロシアム（PvPバトル）

| ID | 要件 |
|---|---|
| BAT-01 | 他ユーザーのクローンデータとターン制バトルができること |
| BAT-02 | ティアポイント制（ブロンズ〜チャレンジャー）でランキングを管理すること |
| BAT-03 | 入場チケット制（時間経過で補充）を採用すること |
| BAT-04 | リアルタイムランキング表示ができること |
| BAT-05 | シーズン終了時に上位者へ称号を付与できること |

### 3.8 ライブチャンネル

| ID | 要件 |
|---|---|
| LIV-01 | 4チャンネル（廃墟・広場・ビーチ・祭壇）の匿名リアルタイムチャットが利用できること |
| LIV-02 | チャットメッセージは5秒後に自動削除されること |
| LIV-03 | スパム防止のためのクールダウンを設けること |
| LIV-04 | WASDおよび方向キーでアバターを操作できること |

### 3.9 ローグライク（カードバトル）

| ID | 要件 |
|---|---|
| ROG-01 | カードバトル形式のローグライクゲームを提供すること |
| ROG-02 | クリアごとに報酬を付与すること |
| ROG-03 | クリア回数を記録・表示すること |

### 3.10 遠征

| ID | 要件 |
|---|---|
| EXP-01 | ケボモンを編成して遠征させることができること |
| EXP-02 | 遠征完了時にポイント・強化石・卵を報酬として付与すること |
| EXP-03 | 遠征回数を記録・表示すること |

### 3.11 通知

| ID | 要件 |
|---|---|
| NTF-01 | コメント・業績達成・称号獲得をリアルタイム（WebSocket）で通知すること |
| NTF-02 | Web Push 通知をオプトイン方式でサポートすること |
| NTF-03 | 未読通知件数をバッジで表示すること |
| NTF-04 | 通知の既読・削除ができること |
| NTF-05 | 通知内容をユーザーの言語設定に合わせて表示すること |

### 3.12 設定・プロフィール

| ID | 要件 |
|---|---|
| SET-01 | ダークモード / ライトモードを切替できること |
| SET-02 | テーマカラー（10色）を変更できること |
| SET-03 | 表示言語を韓国語 / 日本語から選択できること |
| SET-04 | プロフィール名・アイコン写真を変更できること |
| SET-05 | 設定はサーバーに同期し、デバイス間で共有されること |

## 4. 非機能要件

### 4.1 パフォーマンス

- API 応答時間: 通常リクエスト 95 パーセンタイルで 500ms 以内
- WebSocket 接続: 複数ユーザーの同時接続をサポート

### 4.2 セキュリティ

- 認証には JWT（Bearer トークン）を使用すること
- パスワードは bcrypt でハッシュ化して保存すること
- メール認証コードの有効期限を設けること

### 4.3 可用性・スケーラビリティ

- データベースは MySQL を使用し、Prisma ORM で管理すること
- フロントエンドは Vite でビルドし、静的ファイルとして配信可能なこと

### 4.4 多言語対応

- 韓国語（ko）・日本語（ja）の2言語をサポートすること
- 言語設定はアカウントに紐づけてサーバーに保存すること
- 未ログイン状態でも言語選択ができ、ログイン後に引き継がれること

---

## 5. 制約事項

- Web アプリケーションとして提供し、ネイティブアプリは対象外とする
- 通貨は KRW（韓国ウォン）・JPY（日本円）に対応する
- ソーシャルログインは LINE / Apple は将来対応（現状 Comming Soon）
